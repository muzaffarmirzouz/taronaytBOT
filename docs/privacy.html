Privacy Policy

Last updated: November 2026

Music Bot is a private tool operated by its owner for uploading the owner's own videos to the owner's own YouTube channel.

Data we access

The app requests only the YouTube upload permission (youtube.upload) for the owner's Google account. It uses this permission solely to upload videos, titles, descriptions, tags and thumbnails that the app itself generated.

Data we store

The OAuth refresh token is stored as a private environment variable on the owner's own server. It is not shared with anyone. The app does not collect, sell or share personal data of any other person.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
